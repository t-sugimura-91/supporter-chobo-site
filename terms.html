サポ帳 利用規約

制定日: 2026年11月18日

最終更新日: 2026年11月18日

この利用規約(以下「本規約」)は、「サポ帳」(以下「本アプリ」)の利用条件を定めます。本アプリを使うことで、本規約に同意したものとみなします。

1. 本アプリについて

本アプリは、サッカー観戦にかかった費用を、試合ごと・シーズンごとに記録・集計するアプリです。本アプリは、特定のクラブ、リーグ、団体と関係のない、個人が開発したアプリです。

2. 記録の取り扱い

  • 利用者が入力した記録は、利用者の端末に保存されます。端末の故障、紛失、アプリの削除によって記録が失われても、開発者は復元できません。
  • 記録の正確さは、利用者の入力によります。集計結果は、参考のための表示です。

3. 無料の範囲と有料プラン(シーズンパス)

3.1 お試し期間

初回の起動から14日間は、有料の機能をすべて使えます。支払い情報の登録は不要で、自動で課金されることはありません。期間が過ぎると、無料の範囲に戻ります。記録したデータは、消えません。

3.2 有料プラン

プラン料金(税込。App Store の表示に従う)期間
月額300円1か月ごとに自動更新
年額2,400円1年ごとに自動更新
  • 料金は、購入の確定時に、利用者の Apple ID に請求されます。
  • 現在の期間が終わる24時間前までに解約しない限り、同じ期間で自動的に更新されます。
  • 更新の料金は、現在の期間が終わる24時間前までに、Apple ID に請求されます。
  • 購読の管理と解約は、端末の「設定」の Apple ID の「サブスクリプション」、または App Store のアカウントのページから行います。アプリの中では解約できません。「課金を停止する」のボタンは、その管理画面を開きます。
  • 解約しても、支払い済みの期間の終わりまでは、有料機能を使えます。
  • 支払い済みの料金の返金は、Apple の規約と手続きによります。

3.3 有料機能

観戦成績、シーズン振り返りと共有画像、試合の写真(1試合につき3枚まで)などです。内容は、アプリ内の表示に従い、今後、変更することがあります。

  • 本アプリは、クラブのエンブレム、リーグのロゴなどを含みません。クラブ名は、利用者が入力した文字列です。

開発者は、事前の通知なく、本アプリの内容を変更し、または提供を終了することがあります。終了するときは、可能な限り、事前にお知らせします。
